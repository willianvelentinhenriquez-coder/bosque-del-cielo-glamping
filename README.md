# 🏞️ Bosque del Cielo - Cabañas & Glamping (El Salvador)

Landing page para **Bosque del Cielo**, un alojamiento turístico boutique ficticio ubicado en La Ruta de las Flores (Apaneca, El Salvador).

Este proyecto forma parte de la actividad evaluada de **Desarrollo Frontend**, enfocado en la temática de **Alojamientos Turísticos en El Salvador**.

---

## 🌐 Enlace del Sitio Publicado
🔗 **URL Pública:** [https://tu-usuario.github.io/bosque-del-cielo-glamping/](https://tu-usuario.github.io/bosque-del-cielo-glamping/)

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica completa (Hero, Navbar, Nosotros, Cabañas/Tarifas, Formulario y Footer).
- **CSS3:** Variables, CSS Grid para tarjetas, Flexbox para la barra de navegación y Media Queries para 3 tamaños de pantalla.
- **JavaScript (ES6+):** Manipulación dinámica del DOM, menú hamburguesa en móviles, animación de navbar al hacer scroll y validación de formulario.
- **Iconos y Fuentes:** FontAwesome 6 y Google Fonts ('Montserrat', 'Open Sans').

---

## ✨ Funcionalidades

1. **Navbar Interactiva:** Cambio de estilos en scroll (`.scrolled`) y menú hamburguesa colapsable con JS nativo (`querySelector`, `addEventListener`, `classList`).
2. **Validación de Formulario Completa:**
   - Control de campos vacíos.
   - Validación de e-mail mediante Expresión Regular (**Regex**).
   - Limpieza automática de errores mientras el usuario escribe (`input` event).
   - Confirmación de éxito personalizada al enviar la reserva.
3. **Contenido 100% Real:** Cero uso de *Lorem ipsum*.
